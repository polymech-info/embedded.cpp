# JC8012P4A1

10.1-inch Guition panel, ESP32-P4 plus ESP32-C6. Seller string `JC8012P4A1`. The factory pack is published as `JC8012P4A1C_I_W_Y`.

Cloned from [guitionofficial/P4-series](https://github.com/guitionofficial/P4-series) (master, 3 Nov 2026) into `vendor/JC8012P4A1/P4-series`, sparse to this product only. Schematic, specification, and the preloaded demo are in that tree. [p1ngb4ck/unofficial_guition_esp32p4_repo](https://github.com/p1ngb4ck/unofficial_guition_esp32p4_repo) and [profi-max/JC8012P4A1_BSP_ESP32P4](https://github.com/profi-max/JC8012P4A1_BSP_ESP32P4) republish the same Guition pages and demos.

## Factory application

The desktop on a new board is `esp_brookesia_phone`: Espressif’s phone launcher, stylesheet `ESP_BROOKESIA_PHONE_800_1280_DARK_STYLESHEET`. `main/main.cpp` installs a Squareline gadget, calculator, music player, settings, 2048, camera, image display, a “new app”, touch draw, and the video player when an SD card mounts. `bsp_extra_codec_init()` runs before the UI.

Settings shows `APP_SOFTWARE_VERSION`. Match that string to the copy on disk:

| About version | Tree | Built with |
|---|---|---|
| v3.3.0 | `1-Demo/IDF_5.5.4/JC8012P4A1C_I_W_Y_Old_Panel/esp_brookesia_phone` | ESP-IDF 5.5.4 |
| v4.3.0 | `1-Demo/IDF_5.5.4/JC8012P4A1C_I_W_Y_New_Panel/esp_brookesia_phone` | ESP-IDF 5.5.4 |
| v4.4 | `1-Demo/P4V3X_demo/IDF_6.0.2/JC8012P4A1C_I_W_Y_NewPanel(P4V3x)/esp_brookesia_phone` | ESP-IDF 6.0.2, chip rev below v3 (`REV_MIN_0`, `REV_MAX_FULL=199`) |

Paths are under `vendor/JC8012P4A1/P4-series/JC8012P4A1C_I_W_Y/JC8012P4A1C_I_W_Y/`. Our installed toolchain is ESP-IDF 6.1. The v4.4 tree is the closest of the three.

## Schematic and pins

`5-Schematic/JC8012P4A1.pdf`, with the codec page also at `5-Schematic/7_CODEC.png`.

The codec page draws an onboard MEMS microphone, **MSM381A3729H9CP**, into the ES8311 analog inputs `MIC1P` / `MIC1N`. It is a small part beside the codec. The same page has the NS4150 speaker amplifier and a 2-pin speaker connector. The BSP sets `BSP_CAPS_AUDIO_MIC` and `digital_mic = false`.

| Signal | GPIO |
|---|---|
| I2C SDA / SCL | 7 / 8 |
| I2S MCLK, BCLK, LRCK | 13, 12, 10 |
| I2S DOUT (speaker, codec DSDIN) | 9 |
| I2S DIN (mic, codec ASDOUT) | 11 |
| Speaker amp enable `PA_CTRL` | 20 |
| LCD reset / backlight | 27 / 23 |
| Touch reset / interrupt | 22 / 21 |

I2S DIN on this panel is GPIO 11. The JC-ESP32P4-M3-DEV playground uses GPIO 48 and a different amp pin. `hello-p4` will not exercise this microphone.

Display in the phone demo is the JD9365 at 800×1280. Touch is the GSL3680 on the same I2C bus. Wi-Fi is the onboard ESP32-C6 over SDIO, reset GPIO 54, CLK 18, CMD 19, D0–D3 14–17.
